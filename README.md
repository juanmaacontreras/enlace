# Enlace

Links an Android phone and tablet to a Linux PC on the same Wi-Fi: use the device as the PC's
microphone, share text, images and files into the PC's clipboard, and run PC commands from
buttons in the app. No accounts, no cloud.

- `pc/` — the service (`enlace serve`, `enlace pair`, `enlace devices`, `enlace unpair`).
- `app/` — the Android app.
- `docs/contract.md` — the wire format both implement. `docs/modules.md` — how to add a feature.

See `CLAUDE.md` for how to build and check it.
